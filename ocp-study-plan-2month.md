## Ground Rules

- **Read the full chapter first.** Review questions come only after the whole chapter is done.
- **Tuesday evenings + Wednesday up to 1 PM** are reserved for Java club — unstructured practice time (whatever fits that week).
- **Friday + Saturday:** lighter days — review, coding, practice questions only. No new chapters.
- **Pregnancy flex:** if a day is rough, drop to just the reading and skip questions. There's buffer in the plan.

## Java 21 Topics — Must Know Cold

| Topic | Chapter | What to lock in |
|-------|---------|----------------|
| Pattern matching in `switch` | Ch 3 | Type patterns, `when` guards, null case |
| Sealed classes | Ch 7 | `permits`, `sealed`/`non-sealed`/`final` subclass rules |
| Records | Ch 7 | Compact constructors, no inheritance, generated `equals`/`hashCode`/`toString` |
| Virtual threads | Ch 13 | `Thread.ofVirtual()`, best for I/O-bound not CPU-bound |
| Sequenced collections | Ch 9 | `SequencedCollection`, `SequencedMap`, reversed views |
| Text blocks | Ch 1 | Incidental whitespace stripping, `\` line continuation |

## Review Questions Strategy

- Only start review questions after finishing the full chapter
- Log your score per chapter — anything under 70% means re-reading that section and writing a code example
- Wrong answers: read the explanation, then write a minimal test case that proves the correct behavior
